SAÉ - Machine Learning & Prédiction Médicale

Contexte du projet

Ce projet marquait mon introduction aux méthodes d'Apprentissage Automatique (Machine Learning) appliquées à un cas médical concret. L'objectif était de développer un algorithme capable de prédire une variable quantitative continue : le diamètre d'une tumeur cancéreuse. Pour ce faire, le modèle devait s'appuyer sur une base de données contenant les résultats de dix tests médicaux (les prédicteurs quantitatifs X1 à X10).

Les Défis et le Nettoyage des Données

La qualité d'un modèle prédictif dépendant directement de la qualité des données en entrée, une grande partie du travail s'est concentrée sur la phase de Data Cleaning. J'ai dû identifier et traiter les valeurs manquantes ainsi que les valeurs extrêmes (aberrantes ou atypiques). Pour évaluer l'impact de ces anomalies, j'ai mis en place différentes stratégies : suppression totale des outliers, conservation, et application de méthodes d'écrêtement statistique.

Outils & Modélisation

L'intégralité du traitement a été réalisée en Python. J'ai utilisé la librairie Scikit-Learn pour concevoir, entraîner et tester plusieurs modèles de Régression Linéaire Multiple (RLM). L'objectif était de comparer les performances prédictives de chaque modèle selon le traitement appliqué aux données brutes en amont.

Résultats & Bilan personnel

Le livrable final comprenait le code Python complet ainsi qu'un rapport d'analyse justifiant mon modèle préféré en fonction des métriques d'erreur. Cette SAÉ m'a fait comprendre la réalité du métier de Data Scientist : la modélisation sous Scikit-Learn n'est que la partie émergée de l'iceberg, l'essentiel du travail résidant dans la préparation minutieuse et la compréhension du jeu de données.
