SAÉ - Site Web Dynamique : Musées de France

Contexte du projet

Ce projet en équipe nous plongeait dans les technologies "Full-Stack". L'objectif était de développer une application web dynamique en partant d'une feuille blanche, en exploitant une source de données gouvernementale (OpenData). Nous avons choisi de valoriser le patrimoine culturel français en intégrant la base de données officielle recensant l'ensemble des musées de France.

Architecture & Back-end PHP/MySQL

Le développement a commencé par l'élaboration d'un diagramme UML des cas d'utilisation pour cibler les besoins des administrateurs et des utilisateurs finaux. Nous avons ensuite structuré une base de données MySQL relationnelle et codé un script d'importation PHP pour ingérer le jeu de données externe. Le site embarque un système d'authentification par mot de passe utilisant les variables de sessions, ainsi qu'une interface d'administration permettant d'effectuer des opérations CRUD (Création, Lecture, Modification et Suppression de musées) directement via des requêtes SQL dynamiques.

Front-end & Tableau de Bord Javascript

Côté interface, nous avons conçu une charte graphique HTML/CSS entièrement "responsive". La fonctionnalité centrale de l'application est un tableau de bord analytique généré en JavaScript (avec jQuery). En s'inspirant des plateformes de Dataviz modernes, nous avons créé au moins 5 indicateurs interactifs : une cartographie des établissements, des diagrammes en barres sur la répartition par région, et des graphiques circulaires illustrant les types de collections exposées.

Livrables & Restitution

Le rendu incluait l'archive complète de l'application, le script d'export SQL de la base de données, et un bilan technique PDF décrivant l'organisation du groupe, les succès rencontrés, et une transparence totale sur l'utilisation d'outils d'intelligence artificielle lors du débogage du code Javascript.
